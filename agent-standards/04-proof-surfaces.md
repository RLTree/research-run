# Proof Surfaces

- Source, package, install, cache, discovery, runtime, journey, GitHub, real-use,
  release, and product proof are not interchangeable.
- Source-derived UltraGoal standards support repository source-governance claims
  only. They do not prove the installed plugin cache, command discovery, runtime
  activation, reviewer exposure, or Research Run product behavior.
- Proof binds to an exact clean commit or named immutable artifact. Dirty or
  wrong-candidate observations cannot move a claim unless the claim explicitly
  names that candidate form.
- Receipts and prose cannot raise claims. Persist only the smallest artifact
  required for a current claim, handoff, irreproducible observation, or recovery;
  otherwise keep evidence ephemeral.
- A conflicting fit plan is read-only evidence. Apply only an exact accepted,
  preservation-proven plan whose retained files have current operational purpose.
- Failures name the affected surface, exact candidate, narrow rerun, and claims
  blocked or withheld.
