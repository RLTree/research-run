# Research Run Agent Contract

`STANDARD.md` and `policy.toml` govern this repository. The active ExecPlan and
evidence/decision record own the current v0.1 scope. Report conflicts instead of
silently weakening inherited law.

- Preserve one authority path: parse typed records, validate references and
  confinement, then publish canonical state atomically.
- Canonical records may raise a workspace assessment only through an explicit
  human `ReviewDecision`. Status, receipts, examples, generated prose, and retries
  are derived or contextual and cannot promote claims.
- Keep observations distinct from interpretation and retain negative and
  ambiguous outcomes.
- Fail closed on malformed input, unknown versions or references, symlinks,
  path escape, ambiguous prior effects, budget exhaustion, and identity conflict.
- Keep source, package, install, runtime, journey, GitHub, release, and real-use
  proof distinct. Never claim scientific truth from workspace validation.
- Rust is the v0.1 product language. Do not add services, UI frameworks,
  databases, telemetry, LLM providers, or scale machinery without a measured
  trigger and a new approved contract.
- Before committing, run the current gates in `STANDARD.md`. Preserve unrelated
  work and make coherent feature-branch commits. Do not merge or release.
